Git cheat sheet

- git init (makes a repository out of the directory) git init
- git add (addes the file and with git add . you can add all at once) git add index.html
- git commit -m "" (commits the file with a commit message) git commit -m"the big changes"
- git status (shows the status of your repository)
- git log (shows the log of your repository)
- git clone (clones the git hub repository) git clone https://github.com/TobiasKlosz/tobias-klosz-personal-info.git
- git pull (pulls the current repositor from git hub)
- git push (pushes your changes to git hub)
